# PDFie 0.4.1

## 수정
- **Codex CLI를 업데이트해도 AI 학습 기능이 계속 동작합니다.** 이전에는 검증한 0.160.0과 정확히 같은 버전만 허용해서, Codex가 업데이트되면 “이 Codex CLI 버전은 아직 검증되지 않았습니다” 안내와 함께 생성 기능이 꺼졌습니다. 이제 0.160.0 이상이면 안내 없이 사용할 수 있습니다.
  - 안전 장치는 그대로입니다. 매 요청마다 Codex가 읽기 전용·네트워크 차단·실행 환경 없음 상태인지 확인하고, 도구 실행 요청은 거부합니다. 이후 Codex 업데이트로 이 확인 방식이 바뀌면 생성은 안전하게 멈추고 이유를 알려 줍니다.
  - 0.160.0보다 오래된 버전은 업데이트하라는 안내가 나옵니다.
  - 설정의 ChatGPT 계정 항목에서 설치된 Codex CLI 버전을 확인할 수 있습니다.

## 설치
- Apple Silicon Mac, macOS 14 이상.
- 이 빌드는 Apple 개발자 서명과 공증을 거치지 않았습니다. 처음 열 때 macOS가 막으면 Finder에서 앱을 Control-클릭한 뒤 **열기**를 고르거나, 터미널에서 `xattr -dr com.apple.quarantine /Applications/PDFie.app`을 실행하세요.
