# PDFie 0.4.0

화면 전체를 [Astryx](https://github.com/meta/astryx) 디자인 시스템 위에서 다시 만든 릴리스입니다. 기능과 저장된 학습 기록은 그대로이고, 읽기에 방해되지 않는 차분한 화면으로 바뀌었습니다.

## 리더
- 창 제목줄과 하나로 합친 타이틀바: 문서 제목, 검색·캡처·주석, **Ask AI**, 문서 메뉴(문서 유형, 회전, 집중 모드, 내보내기, 설정, 닫기)
- 문서 위에 떠 있는 페이지 컨트롤: 한/두 페이지 보기, 실제 크기·페이지 맞춤·너비 맞춤, 확대·축소, 쪽 번호 입력
- **집중 모드**(`F`): 페이지만 남기고 모두 숨기기
- 텍스트를 선택하면 나오는 카드: 하이라이트(`H`)·밑줄(`U`)·주석·복사, 다섯 가지 색, AI에게 묻기·요약하기·**쉽게 풀어 설명**·**용어·개념 정의**·소리 내어 읽기
- 주석 패널을 하이라이트 색으로 구분한 카드로 정리

## AI 학습 공간
- 답변의 페이지 근거를 해당 문장 끝에 바로 표시하고, 문서를 넘어서는 주장(해석·추론, 배경 설명, 교육용 예시, 근거 부족)에만 표시
- 대화가 비어 있을 때 시작 질문(핵심 주장 요약, 연구 방법 정리, 한계와 반론) 제공
- 질문 입력창 하나에 인용 구절·캡처·질문 범위·전송을 모음
- 하단에 모델 연결 상태와 글자 크기(A−/A+)
- 학습 목표·섹션 목록에 이해 점검 진행 막대와 행 메뉴(편집·이동·나누기·합치기·삭제)

## 학습 서재
- 검색과 **추가** 메뉴(PDF 열기, 여러 PDF 가져오기, 폴더 가져오기)가 있는 타이틀바
- 자료 종류·주제·컬렉션 사이드바, 적용된 조건은 지울 수 있는 칩으로 표시
- 주제 색 배지와 이해 점검 진행 막대를 보여 주는 카드, 표 형태의 목록 보기
- 가져오기 진행 상황 배너, 주제 정리·컬렉션·제목 바꾸기 대화상자, 삭제 확인 창
- 분류 입력에서 비슷한 기존 주제를 추천

## 설정
- macOS 환경설정 형태로 재구성(AI 연결, 화면)
- ChatGPT 연결 상태와 사용량 막대, 이미지 지원 여부가 보이는 모델 선택
- **새 기능 — 화면 모드:** 시스템 설정·라이트·다크를 모든 창에 적용

## 그 밖의 변경
- 오류와 알림을 화면 오른쪽 아래 토스트로 표시
- 저장된 목표 설명과 수업을 다시 열 때의 문제 수정

## 설치
- Apple Silicon Mac, macOS 14 이상. Astryx 메뉴와 툴팁이 정확한 자리에 뜨려면 최신 Safari(WebKit) 업데이트가 필요합니다.
- 이 빌드는 Apple 개발자 서명과 공증을 거치지 않았습니다. 처음 열 때 macOS가 막으면 Finder에서 앱을 Control-클릭한 뒤 **열기**를 고르거나, 터미널에서 `xattr -dr com.apple.quarantine /Applications/PDFie.app`을 실행하세요.
- 앱을 외장 볼륨에서 바로 실행하지 말고 `/Applications`로 복사해서 여세요.
